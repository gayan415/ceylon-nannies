# Ceylon Nannies

Trusted nanny & babysitter service for traveling families — Sri Lanka's south coast (Galle to Tangalle).

**Live site**: [www.ceylonnannies.com](https://www.ceylonnannies.com)

## Features

- In-hotel & in-villa nanny service with live camera access (Zoom Pro)
- English-speaking, background-verified nanny
- Live USD → LKR exchange rate conversion
- WhatsApp booking flow
- SEO optimized for south coast Sri Lanka

## Tech Stack

- **Framework**: Next.js 15 (App Router, static export)
- **Styling**: Tailwind CSS
- **Hosting**: Vercel
- **DNS**: AWS Route 53
- **Exchange Rate**: open.er-api.com (free, 6hr cache)
- **Analytics**: Google Analytics (GA4)

## Development

```bash
npm install
npm run dev
```

## Deploy

Pushes to `main` auto-deploy to Vercel.
